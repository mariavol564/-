Random Task Generator

Автор:Волкова Мария Дмитриевна

Описание

Приложение для генерации случайных задач. 

Позволяет:
Генерировать случайные задачи из предопределённого списка
Добавлять свои задачи с выбором типа (учеба/спорт/работа)
Фильтровать историю задач по типу
Копировать задачи в буфер обмена
Сохранять историю в JSON-файл

Как пользоваться

1. Получить задачу
Нажмите «Сгенерировать задачу» — появится случайная задача.

2. Добавить свою задачу
Введите название, выберите тип (учеба/спорт/работа), нажмите «Добавить задачу». Пустые задачи добавлять нельзя.

3. Отфильтровать историю
Нажмите «Учеба», «Спорт» или «Работа» — останутся только задачи выбранного типа. Нажмите «Все» — вернутся все.

4. Скопировать задачу
Выделите задачу в истории, нажмите «Копировать задачу» — она сохранится в буфер обмена (вставьте Ctrl+V).

5. Очистить историю
Нажмите «Очистить историю» и подтвердите — все записи удалятся.

Примеры

Нажали кнопку → получили: «📚 Прочитать статью (Тип: учеба)»

Добавили «Выучить Python», тип «учеба» → задача появилась в генераторе

Нажали «Спорт» → в истории остались только спортивные задачи


Тестирование

Запустите в командной строке:

python test_task_generator.py

Если появится OK — всё работает правильно.
